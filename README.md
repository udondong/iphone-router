# 나라가족 5G · iPhone 라우터

가족과 편하게 연결하는 iPhone 핫스팟 웹앱. **v2.3.0**

[앱 열기](https://udondong.github.io/iphone-router/)

## 사용하기

1. iPhone Safari에서 앱을 엽니다.
2. 설정 버튼에서 아이폰 설정에 표시된 Wi-Fi 이름과 비밀번호를 저장합니다.
3. 다른 기기의 카메라로 QR을 스캔합니다.
4. Safari 공유 메뉴에서 **홈 화면에 추가**하면 앱처럼 사용할 수 있습니다.

개인용 핫스팟은 아이폰 설정에서 켜야 합니다. 운영 체크는 직접 기록하는 값입니다. 웹앱은 iOS의 핫스팟 상태·접속 기기·사용량을 읽거나 핫스팟을 제어하지 않습니다.

## 한 번 눌러 켜기 / 끄기 (v2.3.0)

[단축어 다운로드](https://github.com/udondong/iphone-router/releases/download/v2.3.0/Nara-Router.shortcut)

1. iPhone에서 다운로드한 파일을 열어 단축어에 추가합니다. 이름을 **나라가족 라우터**로 맞춥니다.
2. Safari에서 Wi-Fi 이름·암호를 한 번 저장합니다. 홈 화면 웹앱과 Safari의 저장 공간은 다를 수 있습니다.
3. 단축어의 공유 메뉴 → **홈 화면에 추가**로 버튼을 만듭니다.
4. 실행할 때마다 **실제 개인용 핫스팟 전환 → 배터리 읽기 → 기존 QR 상태판 열기** 순서로 동작합니다. 충전 자동화와 저장된 체크값을 사용하지 않습니다.

설정에서 핫스팟을 따로 바꿔도 다음 실행은 실제 상태를 반대로 전환합니다. 셀룰러 데이터가 꺼졌거나 통신사에서 핫스팟을 허용하지 않는 경우는 정상 작동을 보장하지 않습니다. 최종 화면은 Safari이며 잠금 상태에서는 잠금 해제가 필요할 수 있습니다.

상태판은 배터리를 **단축어 실행 시점 값**으로 표시합니다. 핫스팟 켜짐/꺼짐은 제어센터에서 확인하세요. 웹 화면은 전환 후 실제 상태를 읽지 않으며 수동 체크를 자동 변경하지 않습니다. 암호는 단축어/URL에 포함하지 않습니다. 배터리는 서버에 전송되지 않는 URL fragment로 전달하고 즉시 주소에서 지웁니다.

실행 URL을 받는 것만으로는 핫스팟을 전환하지 않습니다. 새로고침·뒤로가기·오프라인 재실행에서도 임의의 재전환이 없습니다. 첫 실행에서 iOS가 요구하는 권한을 허용해야 합니다. 실제 iOS 27에서 단축어 가져오기/핫스팟 전환 검증은 사용자 기기에서 남아 있습니다.

단축어 원본 생성: `python3 scripts/build-shortcut.py`. Apple `shortcuts sign --mode anyone`으로 서명한 파일은 릴리스 자산으로 제공합니다.

## 디자인과 기능

- 블루·슬레이트·세이지 계열의 솔리드 색상, 큰 QR과 정돈된 카드.
- 자동·라이트·다크 테마, 비밀번호 숨김·보기·복사.
- Wi-Fi 이름·비밀번호 검증과 미설정·저장 오류 안내.
- 한 번 온라인으로 열면 저장된 QR을 오프라인에서도 다시 볼 수 있습니다.
- 새 버전은 온라인에서 갱신되며 기존 Wi-Fi 정보는 유지됩니다.

## Android 앱에서 가져온 개선 (v2.2.0)

- **거치 상태판**: 큰 QR과 수동 핫스팟·충전 체크를 한 화면에 표시합니다. 지원 브라우저에서는 충전 체크 후 화면 유지를 요청할 수 있으며, 상태판을 닫으면 해제합니다. 실제 전원 연결은 자동 감지하지 않습니다.
- **연결 점검**: 저장 정보와 이 브라우저의 인터넷 응답을 구분해 확인합니다. [Apple 공식 안내](https://support.apple.com/ko-kr/119837)를 바탕으로 연결 문제 해결 순서를 제공합니다.
- **데이터 주기·한도**: 통신사 앱에서 확인한 누적 사용량을 직접 기록합니다. 매월 기준일, 잔여량과 80%·100% 한도 안내를 제공하며, 이전 주기 기록을 보존합니다. 새 주기의 미입력 값은 ‘기록 필요’로 표시합니다. 한도를 비우면 홈에서 사용량 카드를 숨깁니다.

웹앱은 사용량·충전·배터리 온도·셀룰러 신호·접속 기기를 자동 측정하지 않습니다. 한도 안내는 기록한 값을 기준으로 화면에 표시하며 백그라운드 알림을 보내지 않습니다.

## 저장 정보

Wi-Fi 정보·화면 설정·사용량 기록은 이 기기의 브라우저 `localStorage`에만 저장합니다. 서버로 보내지 않습니다. QR은 로컬 번들로 생성하며 외부 QR 서비스나 분석 도구를 사용하지 않습니다.

브라우저 데이터를 삭제하면 저장 정보도 지워집니다. QR에는 연결 정보가 들어 있으므로 신뢰하는 기기에 보여 주세요.

## 개발과 배포

```sh
node scripts/check.mjs
python3 -m http.server 8876 --bind 127.0.0.1
```

`main` 변경 시 GitHub Actions가 구문·자산·아이콘·캐시 격리·오프라인 동작을 검사합니다. 검사가 통과하면 지정한 앱 파일만 GitHub Pages에 게시합니다. 로컬 메모와 화면 검증 산출물은 게시 대상에서 제외합니다.

## 검증 범위

- 320·375·390·430·768px 화면에서 가로 넘침 없음.
- 저장·재실행, 테마 보존, 비밀번호 입력 오류, 수동 체크 보존, 오프라인 QR 재실행.
- macOS Vision으로 한글 Wi-Fi QR 해독 및 문자열 일치 확인.
- WebKit iPhone 12 에뮬레이션에서 상태판 세로·가로 표시, 온라인/오프라인 점검, 사용량 저장·주기 전환·한도 안내를 확인했습니다.
- 화면 유지 허용·거절·요청 중 종료와 저장 실패 복원은 모의 API 상태로 검증했습니다. 실제 iPhone의 화면 유지·홈 화면 설치·Wi-Fi 접속은 실기기 확인이 필요합니다.

QR 라이브러리: [qrcode-generator 2.0.4](https://www.npmjs.com/package/qrcode-generator), Kazuhiko Arase, MIT. 저작권·라이선스는 `vendor/`에 보존합니다.
